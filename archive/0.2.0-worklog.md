# 0.2.0 — consist drag and visible terrain

## Work

- Added aerodynamic skin drag proportional to one locomotive plus the consist's wagon count. Frontal drag remains gauge-based and fixed with train length; the wagon plot now shows the length-scaled skin-drag curve, and the gauge plot uses the total aerodynamic resistance.
- Added a 256-sample, loop-seamless `Float32Array` height profile with gentle seeded relief. Blank worlds remain flat. Height and slope sampling wrap across the ring; world snapshots copy the profile.
- The side view projects elevation at 0.34 px/m. Terrain, track, nodes and train share the profile; a subdued signed-slope palette colors the terrain. Grade remains visual only—no grade resistance or pathfinding yet.
- Updated the market-jump experiment to bound transfers by the build's current hold, since a wide wagon can move more than one unit per wagon at a stop.

## Validation

All README experiments pass: `harness.js`, `world.js`, `economy.js`, `train.js`, `trade.js`, `mass-balance.js`, `tech.js`, `plots.js`, `line.js`, `boot.js`, `surface.js` and `gauge.js`. Checks cover length-scaled drag, plot agreement, flat and generated terrain, height/slope wrapping, copy behavior, terrain-relative hit testing, and the existing economic and movement invariants.

## Next step

If terrain should affect operations, add grade resistance and per-segment speed limits using the existing terrain profile, then validate the effect on stops and line pace before adding pathfinding.
