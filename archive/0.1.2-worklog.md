# 0.1.2 — ticking economy worklog

## Review of 0.1.1

- Re-ran `node experiments/harness.js`, `node experiments/world.js`,
  `node --check` on all scripts, and `git diff --check`: all passed. Ring
  placement, the wrap-seamless camera, and the fixed-step clock are sound.
- Two stale-copy defects in `index.html`: the build badge still read
  `PROTOTYPE 0.1.0` and the "UP NEXT" card still pointed at 0.1.1 — the
  milestone it shipped — while the 0.1.1 worklog claimed both were updated.
  Both are fixed in this milestone's copy pass (badge 0.1.2, next-step 0.1.3).
- One camera defect found while testing: the camera snapped on a seed change
  only if `sim.time < view.lastSimTime` still held at draw time, so a second
  seed change within one frame (or at high speed) skipped the snap and the
  camera drifted across the regenerated world. `Main.setSeed` now calls
  `Render.snapCamera` explicitly and the time-decrease heuristic is gone.
- Minor cleanup: `UI.setSpeed` no longer writes the redundant `.value` on the
  `<output>` element (its `value` reflects `textContent`).

## Implementation

- `js/const.js`: `PRICE_FLOOR = 0.2`, `SPREAD = 0.08`, `RES_COLORS`
  (R1 amber, R2 slate-blue, R3 teal).
- `js/world.js`: the world gains `price` / `consumed` / `overflow` typed
  arrays — a price cache and two ledgers for the conservation check.
- `js/economy.js` (new): the value curve `p(s)`, midpoint unit quotes
  `buyQuote` / `sellQuote` with the spread band, `refreshPrices`, and `tick`:
  source inflow clamped at capacity with the excess accounted as overflow,
  consumer drain gated on every recipe stock holding at least one unit, with
  drained units accounted as consumed. Prices are refreshed per tick so the
  render loop never evaluates `pow()`.
- `js/sim.js`: `Sim.step` ticks the economy before moving the placeholder
  train; `Sim.reset` refreshes prices after regenerating the world.
- `js/render.js`: nodes draw three yard bars above the kind cap with a price
  tick each (tick height = price over `[0, base*(1+SPREAD)]`); `Render.hitNode`
  returns the nearest node inside a 20 px hit width and the node's vertical
  band; the camera snap heuristic is replaced by the explicit snap.
- `js/ui.js` + `js/main.js` + `index.html` + `css/app.css`: canvas hover shows
  a fixed-position, pointer-events-none label with the node kind, its
  emission/recipe line, and per resource `stock/cap` plus buy/sell quotes
  (`—` when that side cannot trade). All string formatting lives in the
  mousemove handler, never in the frame loop.
- `experiments/economy.js` (new): floor price + overflow at a full yard,
  starved-consumer stall (fully starved and half-fed), fed-consumer drain rate,
  price bounds + monotonicity over 20 seeds × 2000 steps, same-node spread
  round trip, stock conservation, economy determinism.
- `experiments/boot.js` (new): stub-DOM boot smoke test — the page boots
  headless, frames tick the economy, the hover label shows/hides, and
  pause/speed/seed respond.
- `experiments/world.js`: added the `hitNode` check and the economy require
  (sim calls into it); `experiments/harness.js` gained the same require.
- `README.md`, `findings-pitfalls-skills.md`, and the `index.html` copy,
  badge, and next-step card updated to 0.1.2 → 0.1.3.
