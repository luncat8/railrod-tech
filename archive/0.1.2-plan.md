# 0.1.2 — ticking economy, no train

Parent stage: `0.1.0-plan.md`. Scope: the world economy ticks — sources fill,
consumers drain, prices follow stock — and the side view shows yard bars,
price ticks, and hover quotes. The train stays the 0.1.1 placeholder; no
money, no loading, no kinematics (0.1.3 / 0.1.4).

## Price model (economy.js)

Single value curve per node/resource; buy and sell are a band around it:

```
fill  f(s) = clamp(s/cap, 0, 1)
p(i,r,s) = base * (PRICE_FLOOR + (1-PRICE_FLOOR) * pow(1-f(s), k_i))
buy(i,r)  = p(i,r, stock-0.5) * (1+SPREAD)   // train buys: node stock s → s-1
sell(i,r) = p(i,r, stock+0.5) * (1-SPREAD)   // train sells: node stock s → s+1
```

- `PRICE_FLOOR = 0.2`, `SPREAD = 0.08` (const.js). Quotes use the midpoint of
  the one-unit stock interval crossed, so an immediate buy/sell of the same
  unit at the same node crosses the same underlying `p` and loses the spread.
- Bounds for every reachable stock: `0 < sell <= price <= buy <=
  base*(1+SPREAD)`, and `price` never leaves `[base*PRICE_FLOOR, base]`.
- `p` at the current stock is cached in `world.price` so the render loop
  never evaluates `pow()`.

## Tick (economy.js, called from Sim.step)

- SRC: `stock += inflow*dt`, clamped at `cap`; the excess is lost and
  accounted in `world.overflow`.
- CON: drains `rate*dt` of every recipe resource per step, but only while
  *all* masked stocks hold at least one unit; otherwise it stalls and its
  stocks freeze. Drained units are accounted in `world.consumed`.
- After each node ticks, its three `world.price` entries are refreshed.

## World state additions (world.js)

```
price[i*3+r]     Float32Array(NODE_N*RES_N)  cached p at current stock
consumed[i*3+r]  Float32Array(NODE_N*RES_N)  CON drain ledger, units
overflow[i*3+r]  Float32Array(NODE_N*RES_N)  SRC overflow ledger, units
```

`Sim.reset` refreshes prices after regenerating the world. The ledgers start
at zero and give the 0.1.4 mass-balance check exact conservation:
`initial + produced == current + consumed + overflow`.

## Render (render.js)

- Node = silhouette + kind cap + three vertical yard bars (R1 amber, R2
  slate-blue, R3 teal; `Const.RES_COLORS`), bar height = stock/cap, standing
  above the cap.
- A price tick crosses each bar at the current price mapped onto
  `[0, base*(1+SPREAD)]`: the tick slides down as the yard fills.
- `Render.hitNode(view, sim, px, py)` — nearest node within a 20 px
  half-width inside the node's vertical band; nearest wins, because narrow
  viewports can place two nodes inside one hit width.

## Hover label (ui.js + main.js + index.html + app.css)

Canvas `mousemove` → `Render.hitNode` → `UI.showNodeLabel(world, i, clientX,
clientY)`: a fixed-position, pointer-events-none panel with the node kind,
its emission/recipe line, and per resource `stock/cap` plus buy and sell
quotes (`—` when the yard cannot trade that side). `mouseleave` or a miss
hides it. All string formatting happens in the event handler, never in the
frame loop.

## Check

`node experiments/economy.js`:

- full yard: stock pinned at cap, price == `base*PRICE_FLOOR`, overflow
  ledger grows by `inflow*dt` per tick;
- starved consumer (recipe input < 1 unit): stocks and consumed freeze;
- fed consumer: consumed == `rate*t` per masked resource, other resources
  untouched;
- bounds over 20 seeds × 2000 steps: `0 <= sell <= price <= buy <=
  base*(1+SPREAD)`, stock within `[0, cap]`, price monotone non-increasing
  in stock;
- spread invariant: buy then sell the same unit at one node crosses the same
  underlying `p`, proceeds < cost;
- conservation: `initial + inflow*t == stock + consumed + overflow` per
  node/resource within float32 tolerance;
- determinism: same seed + same steps → identical stock/price/ledgers.

`node experiments/boot.js`: stub DOM boots the page, drives frames, hovers a
node (label shows/hides), and exercises pause/speed/seed — no throw, telemetry
advances.

`node experiments/harness.js` and `node experiments/world.js` still pass;
`node --check` on all scripts; `git diff --check`.

In the browser: yards fill and drain, ticks slide down as stock rises, hover
a node for quotes, switch seeds (world + prices regenerate), run at 8×.
